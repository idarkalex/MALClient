## What's new in 1.1.0

- Reviews are now fetched directly from the MyAnimeList website, showing the full review list in the same order as on the site. Previously only a small subset of recent reviews was shown, and it didn't match the site's ordering.
- Fixed the season label in the anime details screen (e.g. "Summer 2018" instead of "summer 2018").
- Fixed genre browsing returning empty results for several genres.
- Improved API reliability and data freshness.
